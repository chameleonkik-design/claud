# えほんメーカー

0〜3歳の子に読ませる絵本をつくるツールです。文章を入れると絵本が組み上がり、
そこから絵を動かして仕上げ、画面で読んだり、1枚のHTMLに書き出したり、印刷したりできます。

`index.html` をブラウザで開くだけで動きます。ビルド不要、外部ライブラリなし、通信なし。
（`file://` で直接開いても、ローカルサーバー経由でも動きます）

サンプルとして絵本『**ころころ ぽーん**』（全12ページ）を同梱しています。
初回はこれが開くので、まずは右上の「▶ よむ」を押してみてください。

## つかいかた

### 1. 文章から組み立てる

右側の「文から くみたてる」に、1行1ページでお話を入れて
「えほんに くみたてる」を押します。

```
ころころ ころころ
あっ ねこさん
にゃあ にゃあ ぽーん！
うみに ぽちゃん
おつきさま こんばんは
```

* 「ねこ」「ボール」「うさぎ」などのことばから**絵**を選びます（鳴きごえ・漢字・カタカナも拾います）
* 「うみ」「よぞら」「おへや」などのことばから**背景**を選びます
* 手がかりのないページには、それまでの主役をそのまま置いて間を持たせます
* タイトルは1行目からつきます（あとから表紙で変えられます）
* チェックを外すと「空行でページを分ける」モードになり、1ページに複数行入れられます

### 2. 絵を仕上げる

* **中央のページ**：絵をドラッグして動かせます
* **右側**：ことば・背景・絵のパーツ・大きさ・かたむき・色・前後・むき
* **左側**：ページの並べかえ、追加、コピー、削除

編集内容はブラウザに自動保存され、次に開いたとき続きから編集できます。

### 3. 書き出す

| ボタン | すること |
| --- | --- |
| **ほぞん** | `.ehon.json` として保存（「ひらく」で読み込み） |
| **HTMLに書き出す** | 1枚のHTMLに書き出す。このツールなしで、そのファイルだけで読める |
| **いんさつ** | 1ページ1枚で印刷。紙の絵本にできる |
| **▶ よむ** | 全画面で読む。←→キー・タップ・スワイプでめくる。読み上げ（音声）つき |

## 0〜3歳向けにしていること

* **1ページ1行、大きな文字**：文字は下の白い帯に入り、帯の位置と高さは全ページ共通。誌面がそろいます
* **文字は自動で縮む**：帯に収まる範囲で、いちばん大きいサイズを選びます
* **空白で折り返す**：`ころころ ぽーん` は「ころころ／ぽーん」と、ことばの区切りで改行します（簡単な禁則処理つき）
* **はっきりした形と色**：丸みのある単純な形、高コントラスト、白い絵には縁取り
* **絵は上、文字は下**：絵の置ける範囲は上から66%まで。足もとの高さがそろうように自動配置します

## 絵本データの形

```json
{
  "version": 1,
  "title": "ころころ ぽーん",
  "author": "",
  "age": "0-3",
  "cover": { "scene": { "background": "meadow", "items": [] } },
  "pages": [
    {
      "text": "あっ　ねこさん",
      "scene": {
        "background": "meadow",
        "items": [
          { "shape": "cat", "x": 66, "y": 43, "size": 44, "color": "#f2a65a", "flip": true, "rotate": 0 }
        ]
      }
    }
  ]
}
```

座標はページに対する百分率（0〜100）。`size` は幅、`x`/`y` は絵の中心です。
読み込み時に `book.normalize()` を通るので、値がおかしくても壊れず既定値に落ちます。

## 絵を足す

`js/shapes.js` の `S` に1つ追加すれば、パーツ一覧にも自動で並びます。

```js
S.turtle = {
  label: 'かめ', category: 'どうぶつ', zone: 'ground',
  color: '#7bbf6a', size: 38, bottom: 92,
  draw: function (c) {
    return '<ellipse cx="50" cy="60" rx="30" ry="22" fill="' + c + '"/>' + /* ... */ '';
  }
};
```

* 100×100 のローカル座標に、中心 (50,50) あたりを基準に描く
* `zone` … `'ground'`（地面）/ `'sky'`（空）/ `'any'`
* `bottom` … 絵の下端（ローカル y）。地面に立たせる位置の計算に使う
* `draw(色)` は SVG 文字列を返すだけ。DOM に触らないので Node からも動く

ことばから拾われるようにするには、`js/autolayout.js` の `WORDS` に読みを足します。

```js
['turtle', ['かめ', 'カメ', '亀']],
```
